使用步骤

  1. 设备进入 Mic 页(屏幕显示 BLE: ADVERTISING)。
  2. 点「连接设备」,在弹窗中选择 FoloPassport-Mic。
  3. 按住设备上的 OK 说话 —— 本页实时播放、电平条跳动。
  4. 「开始录制」后再说话,「停止并保存 WAV」导出文件。
  5. 拖动增益滑块并「写入」,设备屏幕的 GAIN 条应同步变化。
需要 Chrome / Edge(Safari 不支持 Web Bluetooth)。若直接打开本文件失败, 可在仓库目录运行 python3 -m http.server 后访问 http://localhost:8000/tools/ble_mic_client.html
